# Example usages in AI-FSM

This repository contains a collection of example Jupyter notebooks that demonstrate how to use the XAI supports through out the key phases of AI-FSM

---

## Example Jupyter Notebooks

The example notebooks are organized into three sub‑folders:

| Sub folder |  What it covers |
|------------|----------------|
| [data_management](data_management/README.md) | Data Profiling, Data Prototype, Data Descriptor, Dataset distance |
| [learning_management](learning_management/README.md) |  Feature importance, saliency maps, uncertainty models |
| [inference_management](inference_management/README.md) |  Search based testings, performance assessment, structural coverage |
| [operational_xai](operational_xai/README.md) |  Python source scripts for Operation and Monitoring stage |

Click the links above to view or download the notebooks directly from the repository.
You can also run them locally by cloning the repository and opening the `.ipynb` files in JupyterLab / Jupyter Notebook / VS Code.
